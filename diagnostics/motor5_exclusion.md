# 5번을 제외하고 다른 관절 구동하기

GUI 위쪽의 **5번 제외하고 구동** 체크박스로 선택합니다. 기본값은 꺼짐이며
GUI를 다시 실행하면 다시 선택해야 합니다.

1. 재생을 정지하고 로봇 동기화를 끕니다.
2. **5번 제외하고 구동**을 켭니다.
3. 전체 토크 ON과 로봇 동기화·모션 재생을 실행합니다.

5번의 탐색, 상태 읽기, 자동 토크 ON, 목표 위치 전송을 제외합니다.
저장된 모션의 5번 각도는 삭제하지 않습니다. 5번 토크 버튼에는 ON 대신
**제외**를 표시합니다. 다른 관절의 오프라인·토크 OFF·확인 실패 검사는 유지합니다.
전체 토크 OFF 명령에는 제외한 5번도 포함해 송신하며, 수신·적용은 보장하지 않습니다.

이 옵션은 5번을 특정 자세로 고정하거나 실제 토크를 ON으로 유지하는 기능이
아닙니다. 기존 GUI는 시작할 때 전체 토크 OFF를 보내므로, 이전 실행에서
5번의 토크가 켜져 있었다고 새 실행에서도 켜져 있다고 가정하면 안 됩니다.
모터 내부 보호 정지를 해제하거나, 전원·배선 때문에 버스 전체가 응답하지 않는
문제를 해결하지는 않습니다. 이번 작업에서 실제 5번의 상태는 측정하지 않았습니다.

다시 5번을 포함하려면 재생·동기화를 끄고 체크를 해제한 뒤 **모터 재탐색**을
누릅니다. 제외 여부 변경 자체는 모터에 명령을 보내지 않습니다.

변경 직전 파일은 `.sdk_gui_backups/before_motor5_exclusion_20261027_202516/`에
보관했습니다. 이전에 적용한 연속 보간이 포함된 버전입니다.
